# Clipboard

A personal, offline-first content library for community managers, creators,
small businesses and online sellers. Clipboard works **directly inside a real
folder on your disk**: it lists your subfolders and files, lets you create
folders and Markdown notes, import media, drag & drop files in, and copy text
to the clipboard — all local, no server, no account.

Built with **Flutter + Dart**, targeting **Windows, macOS, Linux** first
(desktop has full filesystem access) and mobile later.

## How it works

- You pick a **working folder** (your library) on first launch.
- The filesystem is the source of truth: creating a folder makes a real folder,
  notes are real `.md` files, imported media are copied into the folder.
- The app scans the folder and detects subfolders, images, videos and notes.
- **Drag & drop** files or folders onto the window to copy them into the current
  folder.
- Favorites/tags live in a hidden, portable `.clipboard/metadata.json`; deleted
  items move to `.clipboard/trash/` and can be restored.

## Tech stack

- Flutter (stable) · Dart · Material 3
- **Riverpod** — state management
- **GoRouter** — navigation
- `path`, `path_provider` — filesystem paths
- `file_picker` — folder/file selection · `desktop_drop` — drag & drop
- `share_plus`, `video_player` — reserved for upcoming sharing/playback

```text
├── features/

│   ├── home/                # workspace picker + dashboard
│   ├── search/ trash/ settings/
└── shared/                  # enums, cross-feature providers
```

## Getting started

The platform runner folders (`windows/`, `macos/`, …) are generated by Flutter
and not committed. Generate them once, then run:

```bash
flutter create --org com.clipboard --project-name clipboard \
  --platforms=android,ios,windows,macos,web .
flutter pub get
flutter run -d windows      # or -d macos / -d linux
```

> No code generation step is required (the app no longer uses a database).
