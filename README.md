# Clipboard

A personal, offline-first content library for community managers, creators,
small businesses and online sellers. Clipboard centralises, organises and lets
you quickly copy, reuse and share texts, images, videos and social-media posts.

Built with **Flutter + Dart** using a clean, feature-first architecture and
targeting **Android, iOS, Windows and macOS**.

## Tech stack

- Flutter (stable) · Dart with null safety · Material 3
- **Riverpod** — state management
- **GoRouter** — navigation
- **Drift / SQLite** — structured local storage
- `file_picker`, `path_provider`, `path`, `uuid`, `share_plus`, `video_player`,
  `crypto`, `flutter_secure_storage`, `intl`

## Architecture

Feature-first with clear layer separation (presentation / application / domain /
data), plus shared `core` and `shared` layers.

```text
lib/
├── main.dart                # entry point
├── app/                     # app shell, router, theme, constants
│   ├── app.dart
│   ├── router.dart
│   ├── constants/
│   ├── theme/
│   └── widgets/             # AppShell (responsive navigation)
├── core/                    # cross-cutting concerns
│   ├── database/            # Drift tables + AppDatabase
│   ├── l10n/                # lightweight fr/en strings
│   ├── providers/           # database provider
│   ├── services/            # FileStorageService abstraction
│   └── widgets/             # EmptyState, ...
├── features/
│   ├── folders/             # folder domain/data/application/presentation
│   ├── assets/
│   ├── posts/
│   ├── home/
│   ├── search/
│   ├── trash/
│   └── settings/
└── shared/                  # enums, models, cross-feature providers
```

## Getting started

This repository contains the Dart source. The platform runner folders
(`android/`, `ios/`, `windows/`, `macos/`) are generated by Flutter and are not
committed. Generate them once, then run the app:

```bash
# 1. Generate the platform runners (does not overwrite lib/ or pubspec.yaml)
flutter create --org com.clipboard --project-name clipboard \
  --platforms=android,ios,windows,macos .

# 2. Fetch dependencies
flutter pub get

# 3. Generate Drift code (creates lib/core/database/app_database.g.dart)
dart run build_runner build --delete-conflicting-outputs

# 4. Run
flutter run
```

## First-launch behaviour

On first launch the database is created and seeded with:

- the auto-created root folder **Main** (which can never be deleted),
- the default platforms: Facebook, Instagram, TikTok, WhatsApp, LinkedIn, X,
- the stored database version.
