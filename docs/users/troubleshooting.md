# Dépannage

[← Guide utilisateur](./README.md)

## Le dossier de travail ne s'ouvre pas

Causes possibles:

- le dossier a été supprimé;
- l'application n'a plus l'autorisation;
- le stockage externe n'est pas accessible.

Solutions:

1. Ouvrez les paramètres.
2. Changez de dossier de travail.
3. Sur Android, acceptez l'autorisation de stockage si elle est demandée.

## Impossible de créer une note

Vérifiez que:

- un dossier de travail est bien choisi;
- l'application peut écrire dans ce dossier;
- le titre n'est pas vide ou invalide.

## Une image ne s'affiche pas

Solutions:

- vérifiez que le fichier existe encore;
- essayez d'ouvrir l'image avec une autre application;
- réimportez l'image si elle a été déplacée hors du dossier.

## Le partage ne montre pas l'application attendue

La liste des applications de partage est fournie par le système. Influencor
prépare le contenu, mais Android, Windows ou l'application receptrice choisit
les options affichées.

## Un fichier importé n'apparaît pas

Causes possibles:

- format non reconnu;
- fichier JSON incompatible avec les tableaux Influencor;
- import interrompu;
- permission insuffisante.

Essayez de réimporter le fichier ou de le placer dans un format reconnu.

## La corbeille ne restaure pas à l'emplacement d'origine

Si le dossier d'origine n'existe plus, Influencor restaure l'élément à la racine
du dossier de travail.
