# Première Utilisation

[← Guide utilisateur](./README.md)

## Objectif

Ce guide explique comment démarrer avec Influencor et choisir le dossier dans
lequel vos contenus seront organisés.

## Installation

Installez l'application fournie pour votre plateforme:

- Android: fichier APK fourni par le distributeur de l'application.
- Windows: installateur ou exécutable fourni par le distributeur.

## Premier lancement

Au premier lancement, Influencor demande de choisir un dossier de travail.

Ce dossier devient votre bibliothèque principale. L'application y affiche les
fichiers, dossiers, notes, images, vidéos et tableaux.

## Étapes

1. Ouvrez Influencor.
2. Appuyez sur **Choisir le dossier de travail**.
3. Sélectionnez ou créez un dossier.
4. Validez.
5. La bibliothèque s'ouvre automatiquement.

## Résultat attendu

Vous arrivez sur l'écran principal avec le contenu du dossier choisi.

## Sur Android

Si le dossier choisi nécessite un accès spécial, Android peut afficher une
demande d'autorisation de stockage. Acceptez-la si vous voulez que l'application
puisse lire et écrire dans ce dossier.

Si l'autorisation n'est pas disponible, utilisez un dossier privé de
l'application ou choisissez un autre emplacement.

## Compte utilisateur

Influencor ne demande pas de création de compte pour utiliser la bibliothèque
locale.

## Changer de dossier plus tard

Vous pouvez changer le dossier de travail depuis:

**Paramètres → Dossier de travail → Changer de dossier de travail**
