# Limitations Connues

[← Guide utilisateur](./README.md)

## Partage

Influencor ne peut pas forcer une application externe à choisir un mode précis
comme message, post ou story. L'application receptrice décide.

## Tableaux

Les tableaux sont conçus pour des usages simples. Ils ne remplacent pas un
tableur complet.

## Permissions Android

Certains dossiers Android peuvent nécessiter une autorisation spéciale. Si
l'accès est refusé, choisissez un autre dossier ou utilisez le dossier privé de
l'application.

## Web

Le fonctionnement web dépend des limites du navigateur concernant l'accès aux
fichiers locaux.

## Médias

Certains formats d'image ou vidéo peuvent être reconnus mais non prévisualisés
selon les capacités de la plateforme.
