# FAQ

[← Guide utilisateur](./README.md)

## Faut-il créer un compte ?

Non. Influencor fonctionne avec un dossier local.

## Mes fichiers sont-ils envoyés sur un serveur ?

Non pour la bibliothèque locale. Les fichiers restent dans le dossier de travail
choisi. Le partage utilise les applications que vous choisissez dans la feuille
de partage native.

## Puis-je changer de dossier ?

Oui, dans **Paramètres → Changer de dossier de travail**.

## Que devient un fichier supprimé ?

Il est déplacé dans la corbeille de l'application. Vous pouvez le restaurer ou
le supprimer définitivement.

## Pourquoi certains fichiers JSON n'apparaissent pas ?

Seuls les fichiers JSON compatibles avec le format de tableau Influencor sont
affichés comme tableaux.

## Pourquoi une application de partage ouvre un mode publication ?

Influencor transmet le contenu au système. L'application receptrice décide du
mode final: message, publication, story ou autre.

## Puis-je utiliser l'application sans internet ?

Oui pour les fonctionnalités de bibliothèque locale. Certains liens externes ou
services système peuvent nécessiter internet selon la plateforme.
