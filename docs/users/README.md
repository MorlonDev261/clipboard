préparer, retrouver et partager des contenus: notes, images, vidéos, tableaux et

## Résumé rapide

1. Choisissez un dossier de travail.
2. Créez ou importez vos contenus.
3. Classez-les par dossiers.
4. Marquez les contenus importants en favoris.
5. Retrouvez et partagez rapidement.

```mermaid
    A[Choisir un dossier] --> B[Créer ou importer]
    B --> C[Classer]
    C --> D[Retrouver]
    D --> E[Partager]
```
