# Navigation

[← Guide utilisateur](./README.md)

Influencor adapte sa navigation à la taille de l'écran.

## Sur mobile

La navigation principale se fait avec la barre en bas de l'écran.

Écrans principaux:

- **Accueil**: affiche le dossier de travail.
- **Recherche**: recherche dans la bibliothèque.
- **Favoris**: affiche les éléments marqués avec une étoile.
- **Assistant**: espace assistant intégré.
- **Corbeille**: éléments supprimés restaurables.
- **Réglages**: options de l'application.

## Sur desktop ou tablette

Une barre latérale permet d'accéder rapidement aux mêmes sections.

## Ouvrir un contenu

Depuis la bibliothèque:

- un dossier ouvre son contenu;
- une note ouvre l'écran de note;
- une image ouvre l'aperçu image;
- une vidéo ouvre l'aperçu vidéo;
- un tableau ouvre l'éditeur de tableau;
- un autre fichier affiche une fiche d'information.

## Sélection multiple

Un appui long sur un élément active la sélection.

Actions possibles:

- sélectionner tout;
- partager si tous les éléments sélectionnés sont des images;
- déplacer;
- supprimer vers la corbeille;
- annuler la sélection.
