# Images, Vidéos Et Partage

[← Fonctionnalités](./README.md)

## Images

Les images reconnues peuvent être ouvertes dans l'aperçu intégré. Depuis cet
aperçu, vous pouvez:

- voir l'image;
- zoomer;
- ajouter ou retirer des favoris;
- partager l'image;
- supprimer l'image vers la corbeille.

## Vidéos

Les vidéos reconnues s'ouvrent dans un écran de prévisualisation. Selon la
plateforme, la lecture utilise les capacités média disponibles.

## Partager plusieurs images

1. Faites un appui long sur une image dans la bibliothèque.
2. Sélectionnez d'autres images si besoin.
3. Si la sélection contient uniquement des images, le bouton **Partager**
   apparaît.
4. Appuyez sur **Partager**.
5. Choisissez l'application dans la feuille de partage native.

## Résultat attendu

Les images sont envoyées au système comme fichiers image. Les applications
compatibles peuvent proposer l'envoi en message, publication ou autre action.

## Cas particulier

Influencor prépare le partage de manière compatible, mais l'application
receptrice décide toujours comment elle ouvre le contenu.
