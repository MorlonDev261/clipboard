# Notes

[← Fonctionnalités](./README.md)

## Description

Les notes servent à préparer des textes, captions, idées, réponses clients ou
scripts. Elles sont enregistrées comme fichiers `.md`.

## Créer une note

1. Ouvrez un dossier.
2. Appuyez sur **Ajouter**.
3. Choisissez **Nouvelle note**.
4. Renseignez le titre.
5. Écrivez le contenu.
6. Enregistrez.

Résultat attendu: une nouvelle note apparaît dans le dossier courant.

## Éditer une note

1. Ouvrez la note.
2. Appuyez sur l'icône de modification.
3. Modifiez le titre ou le contenu.
4. Appuyez sur **Enregistrer**.

## Images attachées

Vous pouvez ajouter des images à une note. Elles sont conservées dans un dossier
caché associé au dossier de la note et restent liées au contenu.

## Partage

Une note peut être partagée:

- comme texte seul;
- comme texte avec images attachées;
- avec seulement les images sélectionnées si vous avez sélectionné des pièces
  jointes.

## Copie

Le bouton de copie permet de copier le texte, et selon la plateforme, les images
attachées avec le contenu.

## Séparateur de note

Le séparateur sert à découper le contenu en blocs lisibles en mode affichage.
Il peut être configuré globalement dans les paramètres ou par note.

## Erreurs possibles

| Situation | Solution |
| --- | --- |
| La note est vide | Ajoutez un titre ou du contenu avant d'enregistrer. |
| Une image ne s'affiche pas | Vérifiez que le fichier existe encore. |
| Le partage ne propose pas l'application voulue | L'application receptrice décide des options affichées par le système. |
