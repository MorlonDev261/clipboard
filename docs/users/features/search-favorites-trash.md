# Recherche, Favoris Et Corbeille

[← Fonctionnalités](./README.md)

## Recherche

La recherche parcourt la bibliothèque et permet de retrouver rapidement un
contenu par son nom ou son type.

Filtres disponibles:

- dossiers;
- images;
- vidéos;
- notes;
- tableaux;
- fichiers.

## Favoris

Marquez un élément comme favori avec l'étoile. Les favoris sont accessibles dans
l'écran **Favoris**.

Dans la bibliothèque, une étoile apparaît près du menu d'un élément favori.

## Corbeille

Quand vous supprimez un élément, il est déplacé dans la corbeille de
l'application.

Actions disponibles:

- restaurer un élément;
- supprimer définitivement un élément;
- vider la corbeille.

## Attention

La suppression définitive ne peut pas être annulée.
