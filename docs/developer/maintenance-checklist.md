# Checklist De Maintenance Documentation

[← Documentation développeur](./README.md)

Utiliser cette checklist avant de terminer une modification importante.

## Fonctionnalités

- [ ] La documentation utilisateur décrit le comportement visible.
- [ ] La documentation développeur décrit le flux technique.
- [ ] Les écrans concernés sont cités avec des liens.
- [ ] Les limitations connues sont mises à jour.

## Commandes et build

- [ ] Les commandes ajoutées existent réellement.
- [ ] Les chemins de sortie sont corrects.
- [ ] Les problèmes connus sont documentés.
- [ ] Aucun secret réel n'est écrit.

## Navigation

- [ ] Les index `docs/README.md`, `docs/users/README.md` et
  `docs/developer/README.md` pointent vers les nouveaux documents.
- [ ] Les liens relatifs fonctionnent.

## Qualité

- [ ] Pas de duplication inutile.
- [ ] Terminologie cohérente.
- [ ] Les diagrammes reflètent le code.
- [ ] Les exemples sont concrets.
- [ ] Les documents restent lisibles indépendamment.
